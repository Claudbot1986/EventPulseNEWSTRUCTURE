# Locale / i18n

## Sub-features

- Språk väljs i **Profil → "Språk"**: chips med språkets eg namn, `testID="language-section"` och `testID="language-option-<tag>"`.
- Uppslag: sparad preferens `eventpulse.language` → annars enhetens locale (`expo-localization`) → annars `sv`.
- **15 språk** stöds i `i18n/languages.js` (sv, en + no, fi, da, nl, fr …), inte 10 som FEATURE_MAP säger.
- Saknad nyckel **ekar rått**: fallback kedja val → en → sv → **själva nyckeln** (`i18n/translate.js:13-23`).
- Detekterad enhetslocale persisteras vid första start → senare OS-ändringar ignoreras.
- **Innehåll följer språket, inte bara knapparna.** `fetchFeed` skickar alltid `?locale=<uiLanguage>` (`06-UI/services/agentClient.js`) och servern slår upp `event_translations` och väljer korttitel för det språket (`08-Agent/tools/feed_events.ts` → `pickDisplayText`).
- **Två ytor går utanför agentens feed** och hämtar översättningen själva: Hem (`06-UI/screens/HomeScreen.js`) och Karta (`06-UI/components/KartaScreen.helpers.js`) läser `events_public` direkt. Båda använder `06-UI/utils/displayTitles.js` — samma skydd, samma resultat.
- Serverns `POST /agent/preferences` accepterar bara 10 av de 15 språken (`SUPPORTED_CURATED_LOCALES`). Feedens `?locale=` fungerar för alla 15.

## How to get to it (user POV)

Profil → "Språk" → tryck språkchip.

## Driving it with Playwright

Ingen spec ännu. Recept:

1. Öppna appen → "Profil".
2. `await page.getByTestId('language-section').waitFor()`.
3. `await page.getByTestId('language-option-en').click()` → rubriken ska byta till **"Saved & settings"** och `localStorage['eventpulse.language']` ska vara `'en'`.
4. `await page.getByTestId('language-option-sv').click()` → "Sparade & inställningar" tillbaka.

## Gotchas

- **Harness-fallgropar:** `aria-selected` finns inte i DOM (RNW mappar inte `accessibilityState.selected`) — välj via `testID`/text.
- Det finns **två** "Profil"-etiketter (dold + synlig tabbar) → `.last()` eller synlighetsfilter.
- Playwright-konfigen sätter `locale: 'sv-SE'`. Utan det renderar appen engelska och alla svenska selektorar missar.
- Rå nyckel-eko är kod-synligt (`translate.js:23`) men nås inte av någon sträng idag — verifiera det när policytexten repareras.
- `legal.privacy.p2a.body` finns **inte** (bara `.title`/`.bullets`) — det är anledningen till nyckel-ekot i policymodalen.
