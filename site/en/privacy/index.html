2. What data we collect

2.1 Account data (when you create an account)

  • E-mail address (if you sign in via magic link).
  • Apple ID (if you sign in with Apple — we only receive a unique user id, not your e-mail, if you choose to hide it).
  • Auto-generated anonymous user id (if you use the app without signing in).

2.2 User-generated data

  • Events you save, tap on or mark as uninteresting.
  • Venues and artists you follow.
  • Push subscriptions (if you want notifications for specific venues).
  • Conversations you have with the app's built-in event agent.

2.3 Device and usage data

  • Device id hashed as a 64-character hex string (anonymous; cannot be traced back to you without our internal salt key).
  • Language preference.
  • Location (only if you have explicitly granted location access to the app — used to show events near you).

2.4 Anonymous statistics (only if you opt in)

The app has a separate opt-in toggle under Profile → Privacy. Statistics include events like tile_tap, event_view, event_save and similar. No personally identifiable information is included. Statistics are retained for up to 30 days.

  • Push tokens: until you disable push for a venue or delete your account.
